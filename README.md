# 2T Инженер — канал обновлений

Официальный публичный репозиторий согласованных обновлений:

- OTA прошивки модуля ESP32;
- прошивки ядра ЭБУ;
- манифест обновлений для мобильного приложения **2T Инженер**.

Приложение проверяет обновления по постоянному адресу:

```text
https://github.com/t2Engineer/2t-engineer-updates/releases/latest/download/lanza-ds-updates.json
```

## Правила безопасности

- Публикуются только сборки, которые явно согласованы владельцем и прошли доступные проверки.
- Файл уже опубликованного обновления не заменяется: для исправления создаётся новая версия и новый Release.
- Для каждого файла обязательны точный размер в байтах и SHA-256.
- OTA ESP32: `kind=ota`, `target=16MB` или `target=START-4MB`, расширение `.bin`.
- Ядро ЭБУ: `kind=core`, `target=MOTO2` или `target=LEGACY4`, расширение `.bin` или `.crp`.
- Для MOTO2.x вход в loader разрешён только после подтверждённого диагностического маркера и командой `AB 55 AA`. Для старых 4.x используется legacy-команда `AB`.
- BLE v1 остаётся только источником live-телеметрии. Запись ЭБУ через BLE запрещена; установка выполняется через Wi-Fi API модуля после отдельного подтверждения пользователя.
- Приложение скачивает файл только по HTTPS с GitHub, затем повторно проверяет размер, SHA-256 и совместимость цели.
