# 2T Инженер — канал обновлений

Официальный публичный репозиторий согласованных обновлений:

- OTA прошивки модуля ESP32;
- прошивки ядра ЭБУ;
- APK приложения **2T Инженер**;
- единый манифест обновлений для мобильного приложения.

Приложение проверяет обновления по постоянному адресу:

```text
https://github.com/t2Engineer/2t-engineer-updates/releases/latest/download/lanza-ds-updates.json
```

## Правила безопасности

- Публикуются только сборки, которые явно согласованы владельцем и прошли доступные проверки.
- Файл уже опубликованного обновления не заменяется: для исправления создаётся новая версия и новый Release.
- Для каждого файла обязательны точный размер в байтах и SHA-256.
- OTA ESP32: `kind=ota`, `target=16MB` или `target=START-4MB`, расширение `.bin`.
- Ядро ЭБУ: `kind=core`, целевое семейство ядра, расширение `.bin` или `.crp`.
- Приложение Android публикуется в отдельном корневом блоке `app_update`, `target=ANDROID`, расширение `.apk`.
- Для старых 4.x, MOTO1.0–1.8 и подтверждённого 255.255 используется legacy-команда загрузчика `AB`. MOTO1.9 и MOTO2.x используют `AB 55 AA` только после независимого подтверждения версии и диагностического маркера.
- Точное переходное ядро MOTO1.9 R2 встроено в APK и применяется мастером только для безопасного однократного перехода старых ядер.
- BLE v1 остаётся источником live-телеметрии. Запись ЭБУ выполняется через Wi-Fi API модуля после отдельного подтверждения пользователя.
- Приложение скачивает файлы только по HTTPS с GitHub, затем повторно проверяет размер, SHA-256 и совместимость цели.
- APK не устанавливается скрыто: Android показывает системное подтверждение и проверяет подпись.
